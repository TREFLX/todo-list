# To-Do List

Минималистичный список задач на чистом JavaScript с сохранением в localStorage.

🔗 **Живая версия:** [treflx.github.io/todo-list](https://treflx.github.io/todo-list/)

## ✨ Функционал

- ➕ Добавление задач через форму (Enter или кнопка)
- ✅ Отметка задач как выполненных (клик по задаче)
- 🗑 Удаление задач (крестик справа)
- 🔍 Фильтры: Все / Активные / Выполненные
- 💾 Сохранение в localStorage — данные не теряются при перезагрузке
- 📱 Адаптивная вёрстка

## 🛠 Стек

- **HTML5** — семантическая вёрстка
- **CSS3** — Flexbox, адаптив, transition
- **JavaScript (ES6+)** — без фреймворков
  - Делегирование событий (`closest`, `dataset`)
  - Работа с массивами (`map`, `filter`, `forEach`)
  - Иммутабельность (spread-оператор)
  - `localStorage` + JSON

## 🚀 Как запустить локально

1. Клонировать репозиторий: git clone https://github.com/TREFLX/todo-list.git
2. Открыть index.html в браузере.
3. Или запустить через Live Server в VS Code.
